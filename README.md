# Tesla Track V1 — GitHub Pages
Interface moderna e responsiva para PC, iPhone e tablet.

## Publicar
Envie `index.html`, `style.css` e `app.js` para um repositório GitHub.
Depois: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Os dados apresentados são de demonstração. A ligação real ao Tesla Model Y deverá usar um backend seguro + Tesla Fleet API.
